# لوحة الإدارة: Dashboard والتقارير والطباعة وتسجيل الدخول

## Dashboard

تعرض الصفحة مؤشرات الجيمات، الأعضاء، الاشتراكات النشطة والمنتهية، المدفوعات المعلقة، الفواتير والتحصيل، عدد المميزات والـQuotas، وفشل Jobs وOutbox. يمكن تصفية المؤشرات حسب حالة الاشتراك.

تفاصيل الجيمات تُقرأ من:

```text
GET /api/platform/dashboard/tenants?page=1&pageSize=8&search=&status=&planId=
```

ويشمل الصف: اسم الجيم، النطاق الفرعي، الحالة، الخطة، عدد الأعضاء، وتاريخ انتهاء الاشتراك.

## الإشعارات

```text
GET  /api/platform/notifications?search=&type=&isRead=&page=1&pageSize=20
POST /api/platform/notifications/{id}/read
POST /api/platform/notifications/read-all
```

كل العمليات مقيدة بصلاحية `ManagePlatformReports` وبالمستخدم الحالي. لا تعتمد الواجهة على تخزين محلي لحالة القراءة.

## التقارير والتصدير

مركز التقارير يعرض الملخص المالي والتشغيلي من:

```text
GET /api/platform/reports/overview
```

ويضم روابط للتقارير التفصيلية للجيمات، الاشتراكات، الفواتير، المميزات، العمليات، والتدقيق. يمكن تصدير الملخص إلى CSV، كما أن زر الطباعة متاح داخل الغلاف العام للصفحات.

## الطباعة

زر `طباعة الشاشة` يستخدم طباعة المتصفح إلى PDF، مع اتجاه RTL، مقاس A4، إخفاء الـSidebar وأزرار التحكم، ومنع كسر الكروت أثناء الطباعة. لا يتم إرسال بيانات جديدة إلى الخادم.

## تسجيل الدخول

أعيد تصميم الصفحة بصريًا فقط. عقد المصادقة لم يتغير:

```text
POST /api/platform/auth/login
{ "email": "...", "password": "..." }
```

يدعم التصميم التحقق الفوري، إظهار/إخفاء كلمة المرور، اكتشاف Caps Lock، تذكر تفضيل الجهاز، Enter، حالات التحميل، ورسائل الأخطاء مع الإبقاء على `AuthService` كما هو.
